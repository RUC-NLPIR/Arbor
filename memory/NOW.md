## Current limits

- Cooperative same-UID Git is not protected authority.
- Generic Run drains same-PGID and live-subreaper adopted descendants. Public stop
  after leader exit requires the exact bound live local carrier, and uncontained
  descendants cannot produce a clean final.
- Mode-normalizing filesystem and controlled Git optional-lock behavior are facts,
  not protected authority.
- A real external-model Researcher inner loop and async portfolio are not yet
  commissioned.
- Source Gateway, Independent Reviewer, project Skills, MCP parity, Mission
  Supervisor/shared budgets, protected authority, complete K/M/G productization,
  and Arbor retirement remain open. Current evidence makes no “strictly better
  than Arbor” claim.
